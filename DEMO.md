# Tester sans VPS : GitHub Codespaces

1. Sur la page du dépôt : bouton vert **Code** → onglet **Codespaces** → **Create codespace on main**.
2. Attendre 2 à 3 minutes (installation automatique). Ce fichier est réécrit avec les URL réelles dès que le serveur tourne.
3. Si le port n'est pas public : onglet **Ports** en bas de l'éditeur, clic droit sur `8000` → **Port Visibility** → **Public**.

Le jeton de démo est `demo`. Le Codespace s'arrête tout seul après 30 minutes d'inactivité ; le rouvrir relance le serveur.
